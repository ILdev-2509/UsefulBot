# UsefulBot

## Это мой телеграм-бот с множеством полезных функций

## Функции:
- перевод текста с русского на код морзе
- перевод текста с кода морзе на русский
- перевод текста с одной раскладки клавиатуры на другую
- генератор паролей с заданной длиной
- проверка пароля на надежность
- конвертация числа в другую систему счисления
- конвертация арабских цифр в римские
- конвертация римских цифр в арабские

## В будущем планирую добавить: 
- заметки
- напоминалка
- менеджер финансов
- планировщик дел
- сервис с погодой
- сервис с конвертацией валюты
- сервис с конвертацией физических величин
- возможно что-то еще

## Для взаимодействия с ботом используйте клавиатуру в самом боте

## Бот использует написанную мной же API

## Все ошибки бота фиксируются и отправляются администратору
